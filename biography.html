My Path to Software Development

I'm a CS student at FINKI focusing on AI engineering and full-stack development. My coding journey started with competitive programming through MENDO during high school, which taught me how to think through complex problems and write efficient algorithms. That competitive background gave me a solid foundation, but I realized I wanted to build things people actually use, not just solve abstract puzzles.

What I've Built

I've developed several full-stack applications that solve real problems. Some of them are route optimization system using the Travelling Salesman Algorithm with React and Django, an AI-powered resume analysis platform that integrates LLMs for career guidance, and a team collaboration tool built with C# .NET and Firebase. Each project taught me something different about system design, API integration, and building applications that people can actually use.

Technical Focus

I'm particularly interested in system architecture and building applications that integrate AI capabilities. My current work focuses on understanding how to properly implement LLM-powered features and design scalable systems. I approach development with an emphasis on writing maintainable code and solving problems through thoughtful design rather than quick fixes.
